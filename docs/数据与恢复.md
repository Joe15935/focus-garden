# 数据、权限、备份、卸载与恢复

## 数据目录

`~/Library/Application Support/Focus Garden/`

- `rules.sqlite3`：复用Focuser的屏蔽列表、例外、每周计划、额度与拦截记录。
- `garden.sqlite3`：有效专注记录、配置、目标、XP、成就依据与本地拦截计数。
- `study.sqlite3`：学习导航的规则、课表、课程目录、学习记录、复习卡和任务与专注的关联；`study-backups/` 为它的自动备份。详见 [学习导航](学习导航.md)。
- 本机中文网站拦截页（由原生适配层生成）。

Tauri/WebKit界面偏好和缓存可能另在 `~/Library/Application Support/org.focusgarden.local/`、`~/Library/WebKit/org.focusgarden.local/`。这些不是远程存储。

没有账号、遥测、分析SDK、云数据库、会员校验或付费API。mado网址元信息/网站图标网络获取关闭。程序不保存完整浏览历史，只记录匹配到的拦截对象与本地累计。

## 备份

界面支持JSON/CSV导出。JSON用于可读归档；本版本不宣称可一键恢复全部花园状态。完整恢复方法是退出应用后复制整个 `Focus Garden` 数据目录（含存在的SQLite WAL文件）。替换恢复前，先把现有目录重命名留存，绝不直接覆盖唯一副本。

## 系统改动

不修改hosts、DNS、系统代理、SIP、FileVault或Recovery；不注册root服务，不终止其他应用。

可选“登录时启动”由Tauri注册当前用户的登录LaunchAgent，可随时在应用设置关闭。辅助功能和各浏览器自动化授权由macOS维护，必须由本人确认；可在系统设置→隐私与安全性撤销。

## 卸载

1. 完成或安全提前结束当前专注。
2. 在应用中关闭“登录时启动”。
3. 从菜单栏退出。
4. 将实际安装的 `~/Applications/Focus Garden.app` 移到废纸篓。
5. 数据默认保留；需要清理时先备份，再手动处理上述专属目录。
6. 在系统设置撤销“专注花园”的辅助功能和自动化授权。

如果程序不能打开，用活动监视器停止 Focus Garden；在系统设置→通用→登录项移除其自动启动。仅操作名称/标识明确属于 `org.focusgarden.local` 的项目，不修改其他软件的文件或登录项。

## 紧急恢复

活动监视器强制退出或撤销权限会立即停止后续限制；已隐藏应用可从Dock打开。网站提示页只是标签导航，可以输入新网址或关闭该测试标签。本应用没有需要回滚的网络配置。下次启动将未完成Session登记为中断，不把离线时间换算成奖励。

## 从源码更新后权限未生效

本机临时签名随二进制变化，macOS可能仍保留旧签名对应的授权。先退出应用，在系统设置重新添加实际安装包。若系统依旧拒绝，官方的 `tccutil reset Accessibility org.focusgarden.local` 只清除此应用的旧辅助功能授权；之后必须由本人重新开启。不要重置其他应用或直接编辑系统权限数据库。正常重新打开同一安装包不会改变签名。

应用菜单和⌘Q受严格模式约束；macOS Dock原生退出及活动监视器保留为故障恢复出口。退出后限制立即停止，下次启动保留已记录时长并标记未完成会话。

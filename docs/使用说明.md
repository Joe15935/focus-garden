# 专注花园使用说明

## 第一次打开

所有记录均留在本机。首页查看今天的专注、连续天数、等级和花园。首次打开没有虚构历史、示例奖励或假成就。

在设置中授予“辅助功能”，用于辨认前台应用和浏览器当前页面。网站限制还需要对应浏览器的“自动化”，用于把命中规则的当前标签切换到本机提示页。只给需要限制的浏览器授权即可。不申请屏幕录制、通讯录或完整磁盘访问。权限未授予时，设置会显示缺口，不能保证相应拦截。

## 选择分心来源

建立名为娱乐、社交、视频、游戏等的屏蔽列表。新列表默认关闭，编辑不会立即打断当前工作。在应用页点图标加入；受保护的系统/恢复工具不会列为可屏蔽对象。可选屏蔽名单或允许名单。

网站支持域名、通配符、关键词、具体URL路径及例外。学习页面可通过例外规则放行。例外属于对应列表；另一个生效列表仍可拦截同一网址。使用具体域名/路径，避免过宽的关键词误伤学习网站。

在计划页设置每周时段，启用列表后生效。每日额度以当前活动应用或页面实际使用时间计数，后台标签不计费。专注进行时，该次所选列表强制生效，额度不能绕过它；其他列表继续遵循原日程。

## 开始一段专注

写下本段任务、选择类别和时长，再选择约束强度。普通番茄可用25分钟专注+5分钟休息。无需为了记录而启用不必要的列表。

计时保存在SQLite。暂停运行、睡眠或明显时钟跳变期间不补发时长。应用异常退出或电脑重启后，上次未完成专注标为中断，已经记录的真实时间保留。只有完整结束才获得额外10%奖励。

每实际专注1分钟得到1XP，完整结束额外向下取整10%；不足1分钟不会刷出植物或奖励。等级及装扮均通过专注积累。中断不扣过去的XP、不枯死已有植物。

每日连续记录默认门槛30分钟，可在设置调整。连续天数按本地自然日计算，今天尚未达标时保留截至昨天的连续记录，避免当天刚开始就显示断签。

## 提前结束与故障恢复

温和模式可立即结束。专注模式先等待30秒并写明原因。深度专注等待5分钟后输入“我确认提前结束本次专注”，并记录原因。关闭窗口只是隐藏至菜单栏，正在进行的专注继续计时。

确实发生故障时，可用macOS活动监视器强制退出 Focus Garden，或撤销辅助功能/自动化权限。没有永久系统阻断或需要root修复的网络修改。已隐藏的应用可从Dock重新打开。

## 查看与导出

统计可选今天、本周、本月、今年、全部。热力图可选7/30/90/365天，点击一天查看时长、次数和任务。结束后把任务标为完成、部分完成或未完成。

JSON导出包含花园记录与屏蔽列表，CSV便于表格阅读。备份在本机保存，由你选择位置。完整数据库备份请先退出应用，再复制数据目录，详见数据与恢复说明。

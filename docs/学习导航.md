# 学习导航

侧栏「学习导航」把课表、作息规则、课程目录、复习卡和学习记录放在一起，每天回答三个问题：下一项学什么、情况变了怎么调整、停下来以后从哪里继续。全部在本机计算和保存，不联网、不需要账号或付费服务，关掉 AI 也照常工作。

## 第一次使用

1. 打开「学习导航」，选择「导入初始配置或备份」，选你自己的初始配置 JSON（例如交付包里的 `private/user-state.json`），或从空白模板开始。
2. 到「规则与数据」核对：目标年份、剩余课数、每节时长、午休、起床就寝。标着“待核对”的都是初值。
3. 到「课表」放入课表，三种方式任选：
   - **课表截图识别**：一次多选几张每周的课表截图（手机截图、HEIC 都可以）。用 Mac 自带的文字识别在本机读字，再按色块找出每门课、按左侧节次换算钟点，把几周合并成带「第几周」的课程规则。识别结果先列出来给你逐条核对、改地点，确认后才保存。被上方遮住的课、推算出来的时间都会标「需核对」。
   - **日历文件（.ics）**：WakeUp课程表、超级课程表、系统日历等导出的日历文件。支持时区、每周重复、单双周、例外和单次调课；全天事件和不支持的重复规则会列出来，不会被猜着导入。
   - CSV 或手动添加。
   然后确认已核对的周次。没有确认的周只显示已知的课，不会被当成空闲自动排满。
4. 「课表 → 放假与补课日」可以登记法定假期（整段不上课，学习照常）和补课日（例如周六按周三的课表上课）。
5. 「规则与数据 → 地点开放时间」填图书馆、宿舍等的开放时段，安排不会把任务放进关门的时间。
6. 可选：在「规则与数据 → 课程目录」粘贴课程列表（每行 `科目|课名|分钟|位置`），每天三节就会按顺序绑定具体课名和实际时长。

## 每天

- 「今天」显示按规则算出、并经过独立校验的安排。选一份屏蔽列表和强度，点某一项的「开始」，就用花园原有的计时、屏蔽和安全退出开始专注。已有专注进行时不能再开始，学习导航不会结束或缩短它。
- 专注结束后，这一项会问结果：整项完成 / 完成一部分 / 没有完成。也可以不用计时直接「手动记录」。
- 起晚、拖堂、临时有事：点「情况变了：按现在重排剩下的」，填现在的时间和地点，勾掉今天不再做的事，看清楚“保留 / 移动 / 只排剩余 / 不再安排”后再决定是否采用。已经过去的不会被改写成完成。
- 可以把当天安排导出为日历文件（.ics）。这是一次性文件，不是双向同步。
- 规则或课表改了以后，之前采用的重排才会作废；改目标、加复习卡、记录今天听完的课都不会让今天的重排失效。
- 「今天」底部有上周回顾：听完几节（和规则计划的节数对照）、闭卷提取、做题、复测、英语、积压的复习卡。复盘只找差距出在哪里，不把上周没做完的补进本周。

## 专注时的应用限制

专注期间打开被限制的应用，它会像按 ⌘Q 一样被正常退出，后台播放也会停下。如果那个应用先弹出“是否保存”，就改为隐藏窗口，等你自己处理；不会强制结束，也不会丢未保存的内容。

## 在手机上查看

「规则与数据 → 在手机上查看」选一个 iPhone 也能打开的文件夹（例如 iCloud 云盘）。专注花园开着时，会自动把未来 7 天的安排和到期复习写成「学习导航-本周.html」，在 iPhone「文件」App 里点开即可。同目录还有「学习导航-本周.ics」，可以手动加进日历，但重复导入会产生重复日程。

这是只读副本，不是双向同步：记录仍然在 Mac 上做。要在手机上记录就需要服务器或账号，这和「本地、无账号、无订阅」的原则冲突，所以没有做。

## 状态说明

| 显示 | 含义 |
|---|---|
| 找到一份逐项校验通过的安排 | 可行，但不代表最优，也不代表一定做得完 |
| 当前候选时间里没有找到 / 搜索预算用完 | 没找到，不等于做不到；可以自己调整取舍 |
| 有可核依据：必需时长已超过全部可用时间 | 必需任务、固定课程加上躲不开的往返，已经超过全天可用时间，真的排不下 |
| 课表未知或未确认 | 去「课表」确认，未知不等于放假 |
| 首轮课程余量不足 | 需要你确认是否进入“三个法律训练块”阶段，不会自动从第一讲重听 |
| 休息日 | 不安排备考；跑步时段需要你确认 |

在「规则与数据 → 作息与时长」可以打开「某天放不下完整安排时，那天直接不排新课」：这样的日子其余任务照排，新课顺延到下一个学习日（不会变成下一天 6 节）。

需要缩短午休、改课数这类会改变承诺的调整，都必须在「规则与数据」里明确勾选确认；单日午休例外只影响那一天。

## 复习

复习卡只写问题和核对位置，不抄答案。先闭卷回答，再看核对位置。只有“闭卷、回答前没看答案、已对照来源核对”的结果才会延长间隔；看过答案后说顺只算反馈。间隔是 1/3/7/14/30/60/90 天的简单阶梯，不是记忆概率预测。

学习记录分为听完、闭卷提取、做题、延迟复测、英语完成几栏，互不替代。花园经验只来自原有的真实专注计时，导入、重排、手工记录都不发经验。

## 数据、备份与恢复

- 数据文件：`~/Library/Application Support/Focus Garden/study.sqlite3`，和 `garden.sqlite3`、`rules.sqlite3` 分开；学习导航打不开时，花园和屏蔽照常工作。
- 自动备份：每天第一次打开时一份、每周一份，保存在同目录的 `study-backups/`，保留最近 7 份日备份和 4 份周备份。备份用 SQLite 的 `VACUUM INTO` 生成一致副本，不是直接复制正在写的文件。
- 导入 JSON、从备份恢复之前都会先自动再备份一次；导入内容先完整校验，失败时原数据不变。
- 「规则与数据 → 导出 JSON」得到可读的完整备份。**JSON 没有加密**，拿到文件的人能读到你的课表和记录。
- 设置被别处改过（例如同时开着两个窗口）时，保存会被拒绝并提示刷新，不会互相覆盖。

## 节奏与用时

「规则与数据 → 节奏与用时」按剩余课数推算首轮大约什么时候听完：一种按规则节奏，一种按最近 14 天实际节奏（学习日不够 5 天时不推算）。已有 3 节以上完整记录时，会按实际用时（同一节多次续听加总，取 75% 分位）建议每节时长，要你点按钮才会改。这些都是估算。

## 不在这个版本里

AI 批改主观题、手机上记录（双向同步）、排行榜、完整 FSRS 记忆模型、订阅式日历。

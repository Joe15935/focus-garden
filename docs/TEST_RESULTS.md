# Focus Garden 0.1.0 公开验收摘要

验证日期：2026-09-21。验证环境：Apple Silicon、macOS 26.6.2。本页概括本机实测结果；原始日志、会话导出、设备状态和个人路径仅保留在本机，不作为公开仓库内容。

**21 项功能门：20 PASS / 1 FAIL。FAIL 是整机重启未测试，不代表已经观察到重启故障。** 用户选择暂缓重启。PASS 仅适用于下表明确列出的行为，不能外推为长期稳定性或所有成长解锁均已实测。此版本仍是早期验证版。

## 自动化与构建

- `./scripts/check.sh`：250 项 Rust 测试和 207 项前端测试通过，共 457 项；格式检查、Clippy、前端类型检查和生产构建通过。
- `./scripts/build-macos.sh`：完整 `.app` 构建通过，构建产物和已安装应用均通过整包签名核验。
- 使用本机临时签名，未通过 Apple 公证。没有把本机检查写成 GitHub Actions 已验证。
- 发布准备只调整公开文档、忽略规则、旧工作流归档和扩展凭据示例占位；应用源码与上述实测版本一致。

## 修复与恢复观察

验收曾发现应用已经隐藏，但系统 hide 返回值导致程序误报和漏计。修复后以实际隐藏状态确认单次操作，Chrome 与 Calculator 均重新实测并成功记数。未知结果不自动重复派发。

停用所有测试规则后，独立采样确认 Chrome 未隐藏且没有新增事件，但未保持系统前台，不能宣称持续前台恢复测试已通过。Calculator 在较早停用后采样仍为隐藏状态，原因未确认，该次恢复不记为 PASS。网站额度停用后的正常访问已单独验证。

最终应用重开后，数据、辅助功能及三种浏览器授权保持；登录启动已注册，但实际系统登录启动仍待验证。所有测试限制最终关闭。

## 仍存在的限制

1. 整机重启、实际登录自启、长时运行和睡眠/唤醒尚未完成充分实测。
2. 应用限制针对前台应用并隐藏窗口；网站限制针对受支持浏览器的活动页面，不阻断后台网络或音频。系统退出和撤销权限仍是恢复出口。
3. Safari 首次打开本地提示页可能要求确认单个文件；确认后重复拦截已成功，重启后的提示行为未验证。
4. 临时签名没有公证，重新构建或更新签名后可能需要重新授权。
5. 长期成长、连续多日和全部额度/计划边界的实机覆盖有限，详见表格。
6. GUI JSON 保存花园与屏蔽列表，CSV 保存会话；不包含所有额度和全局事件。完整数据目录备份见[数据与恢复](数据与恢复.md)，整机迁移恢复未验证。
7. 主进程空闲短样本 CPU 为 0.0%–0.2%、内存约 120 MiB，未包含全部 WebKit 子进程，不能外推长期功耗。
8. 前端仍有较大构建块提示；部分旧依赖缺少可核对的精确版本许可证全文，原声明和已取得的许可材料已保留，具体范围见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES)。
